# Data

## Included

- `original/HMO_By_Years.xlsx`: the available cleaned/organized HMO workbook used in the research.
- `reported_results/annual_supply_reported.csv`: headline annual supply values transcribed from the report.
- `reported_results/retention_models_reported.csv`: model estimates and p-values transcribed from the report.

## Unavailable original inputs

The Ayton House CSV and the full cleaned historical rental-listing file are no longer available. The relevant code, methodology, report narrative, and reported findings remain included.

## Privacy note

The workbook contains applicant names from a public register. Review whether you want to publish those fields. The analysis itself does not require applicant names, and a privacy-minimized public version can remove that column.
