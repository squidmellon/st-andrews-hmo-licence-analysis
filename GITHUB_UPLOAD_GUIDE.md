# GitHub Upload Guide

1. Create a new public repository named `st-andrews-hmo-licence-analysis`.
2. Upload the contents of this folder, not the outer folder itself.
3. Confirm that `README.md` displays on the repository home page.
4. Add the description: `Longitudinal HMO licence, rental-supply, regression, and historical web-scraping analysis for St Andrews.`
5. Add topics such as `r`, `python`, `econometrics`, `web-scraping`, `housing`, `data-analysis`, and `record-linkage`.
6. Pin the repository on your GitHub profile.
7. Link the resume project title directly to the repository home page.

Before publishing, review the original workbook because it contains names drawn from a public administrative register. If you prefer a minimal public-data footprint, keep the workbook in a private release or remove applicant-name columns while retaining the analytical fields.
