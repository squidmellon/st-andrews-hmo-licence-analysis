# Reproducibility Status

## Fully available

- Original `HMO By Years` workbook
- Full research report
- Cleaned/reconstructed R scripts for HMO-register processing and retention models
- Cleaned/reconstructed Python scripts for historical scraping, rental-data cleaning, and Ayton House analysis
- Original appendix-code transcription
- Reported-result tables and portfolio figures

## Not currently available

The original Ayton House CSV and the complete cleaned historical rental-listing dataset are no longer available. The related code and analysis are intentionally retained because they document the full scope of the completed work. They are not represented as rerunnable from the included inputs.

## Important distinction

Files under `data/reported_results/` transcribe results reported in the original paper. They are included for traceability and presentation; they are not presented as newly reproduced estimates. The HMO workbook allows the central register workflow to be checked and further cleaned when the scripts are run locally.
